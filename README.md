# AI & Security Observatory / AI安全保障オブザーバトリー

編集：神保謙 / Edited by Ken Jimbo

AIと安全保障の変化を観測し、政策と研究をつなぐ日英二言語の研究情報サイト。
A bilingual (Japanese / English) research site observing change at the intersection of AI, security and policy.

## 現在の役割（2026-10-28 から） / Current role

このリポジトリは、Daily Brief の原稿を受け渡す場所として使う。Claude の定期実行が毎朝 `handoff/daily/YYYY-MM-DD.json` と `.md` を作成し、公開サイトの編集・公開を担う ChatGPT が次のURLから取り込む。手順と執筆規則は `docs/DAILY_BRIEF_RUNBOOK.md`（v2）、検証は `node tools/check-handoff.js YYYY-MM-DD`。
This repository now carries the daily brief manuscripts. A scheduled Claude run writes `handoff/daily/YYYY-MM-DD.json` and `.md` each morning; the public site, edited and published through ChatGPT, imports them from:
`https://raw.githubusercontent.com/kenj0126-creator/kenj0126-creator.github.io/main/handoff/daily/YYYY-MM-DD.json`

GitHub Pages（https://kenj0126-creator.github.io/ ）での公開は 2026-10-28 に終了し、終了案内（`retired/`）だけを配信している。以下の `dist/` 以降の説明は旧版の記録である。
Publishing on GitHub Pages ended on 2026-10-28; only a retirement notice (`retired/`) is served. The `dist/` layout below documents the earlier version.

## 構成（旧版） / Layout (earlier version)

| パス / Path | 役割 / Role |
| --- | --- |
| `dist/` | 公開されるファイル一式（HTML・CSS・JavaScript・JSON）。ビルド不要 / Everything that is published, as-is. No build step |
| `dist/ja/`, `dist/en/` | 日英各8ページ / 8 pages per language |
| `dist/config/tags.json` | 統制語彙の唯一の原本 / The single source of truth for the controlled vocabulary |

| `dist/data/weekly/YYYY-Www.json` | Weekly Digest |
| `dist/data/library.json` | 資料台帳 / Library records |
| `dist/data/tracker/` | 国別プロファイル・調達・立場マトリクス / Country profiles, programs, positions |

| `tools/` | 検証・索引生成・単一HTMLプレビュー / Validation, indexing and preview tools |
| `briefs/` | 日次Briefの読み物版（Markdown）。公開対象外 / Readable Markdown briefs, not published |
| `.github/workflows/deploy-pages.yml` | `main` への push で `dist/` を GitHub Pages に配信 / Deploys `dist/` to GitHub Pages on every push to `main` |

## 更新手順 / Updating

```sh
# データを追加・編集したら / after adding or editing data
node tools/index-data.js
node tools/validate.js
node --check dist/assets/app.js
git add -A && git commit -m "brief: YYYY-MM-DD" && git push
```

`main` への push で GitHub Actions が検証を再実行し、通過した場合のみ `dist/` を公開します。検証に失敗した場合は直前の公開版が維持されます。
Every push to `main` re-runs validation in GitHub Actions and publishes `dist/` only when it passes; a failing push leaves the previously deployed version in place.

空ディレクトリ（`dist/data/brief` など）は `.gitkeep` で保持しています。`dist/.nojekyll` により Jekyll 処理は行われません。
Empty data directories are kept with `.gitkeep`; `dist/.nojekyll` disables Jekyll processing.
