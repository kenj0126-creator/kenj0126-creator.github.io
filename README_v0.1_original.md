# AI & Security Observatory · v0.1

設計書 v0.1 の「プロンプト1」に対応する、日英二言語の静的サイトです。全データは表示・操作確認用のサンプルです。

## ファイル構成と役割

| パス | 役割 |
| --- | --- |
| `dist/index.html` | 日本語ホームへの入口 |
| `dist/ja/`, `dist/en/` | Home・Brief・Library・Tracker・Concepts・Cases・Japan Focus・Aboutの16ページ |
| `dist/assets/app.js` | データ読込、検索、複合絞り込み、言語別描画、関連項目の参照 |
| `dist/assets/style.css` | レスポンシブ表示。色・フォントは冒頭のCSS変数で一括管理 |
| `dist/config/site.json` | サイト名、編集体制、クレジット、説明、サンプル表示の設定 |
| `dist/config/tags.json` | テーマ・主体・文書種別・フォーラム・キルチェーン等の統制語彙 |
| `dist/data/index.json` | 日次・週次ファイル、国プロファイル、Markdown本文の一覧 |
| `dist/data/brief/` | 日次Brief。1ファイル1日、項目の配列 |
| `dist/data/weekly/` | Weekly Digest。1ファイル1週、項目の配列 |
| `dist/data/library.json` | 資料台帳。カテゴリ別Essential Readingもここから生成 |
| `dist/data/tracker/` | 国別プロファイル、調達台帳、立場マトリクス |
| `dist/data/open-questions.json` | 未解決の問い・現時点の評価・根拠 |
| `dist/content/` | Concepts、Cases、Japan FocusのMarkdown本文 |
| `tools/index-data.js` | 新しいデータファイルを一覧に登録する補助ツール |
| `tools/export-preview.js` | サーバー不要の確認用HTMLを別ファイルとして書き出す |
| `tools/validate.js` | 必須項目、統制語彙、ID重複、参照先、日付・金額・信頼度の検証 |
| `.openai/hosting.json` | ホスティング設定とサイトID。変更時もIDを維持 |

## 更新手順

1. 該当するJSONまたはMarkdownだけを編集する。
2. ファイルを追加・削除した場合は `node tools/index-data.js` を実行する。
3. `node tools/validate.js` を実行し、全エラーを解消する。
4. 同じサイトの版として保存・公開する。

CSSや描画ロジックは通常のデータ更新では変更不要です。サンプルから実データへ移行するときは、各項目の `sample` を管理し、全サンプルのみの状態を終える際に `site.json` の `sample_mode` と告知文を変更します。項目自身の `sample` バッジは個別に保持されます。原典URL・発行主体・根拠・著者は確認した情報に置き換えてください。

## ローカル表示

依存パッケージ・ビルド処理は不要です。HTTPサーバーの起動が許可された環境で `python3 -m http.server 4317 --directory dist` を実行し、`http://localhost:4317/ja/` を開きます。JSONを取得するため、HTMLを直接ダブルクリックする方式には対応しません。

## Markdown本文

フロントマターは `---` で囲んだJSONオブジェクトです（JSONはYAMLのサブセット）。本文は `<!-- lang:ja -->` と `<!-- lang:en -->` に分けます。見出し、段落、箇条書き、リンク、太字、コード、表に対応します。HTML埋め込みは実行しません。英語本文が未登録の場合は日本語本文を表示します。

## 初版の範囲

8セクション、16ページ、テーマ横断検索、5軸の絞り込み、Briefの日付絞り込み、週次表示、調達段階別表示、立場比較、関連項目へのリンク、概念マップ、用語集、ケース比較、編集方針を実装しています。Brief・Library・調達・立場・未解決の問い・週間項目を各2件、国別プロファイル・論点・ケース・Japan Focus本文を各2本収録しています。

約50件の文献・10か国の本番プロファイル・実際のケース分析の調査は次段階です。自動収集、スケジュール設定、メール配信はこの骨格構築には含めていません。

## 設計書から補った判断

- 静的ホスティングのため、設計書の公開用ツリーを `dist/` に格納。検証・索引作成ツールは公開対象外。
- 読み込むファイル一覧を `data/index.json` に設け、HTMLやJSを編集せず新規ファイルを登録可能にした。
- JSON形式のフロントマターを採用し、外部ライブラリなしでMarkdownを描画。サポートする構文を限定し、HTMLをエスケープする。
- 未確定の金額は `null` を使い、0と区別する。画面には「未登録」と表示。
- 架空の原典URLは `example.com` を使用し、サンプルでは原典リンクを表示しない。
- サンプルの国別立場・戦場の効果は、実際の評価と誤認されないよう全体告知と項目別バッジを併記。
- 国別プロファイルを含む各項目にIDを付与し、文献・論点・ケースと共通の参照方法を使用。
- 日次・週次の定期実行は未設定。自動更新の導入は、実データと掲載方針が確定してから行う。
- サイト名は設計書の推奨案を仮採用。一般向けの公開・名称確定は別段階。

## 検証

`node --check dist/assets/app.js` でJavaScript構文を検証し、`node tools/validate.js` でデータ整合性を確認できます。フィクスチャを別ディレクトリに用意した場合は `node tools/validate.js /absolute/path/to/dist-copy` で検証できます。

## 今回の確認結果と残る制約

日英の一覧・詳細・タブ等54通りの描画処理、内部ルート、複合フィルタ、該当なし表示をプログラムで確認しました。20件のレコード、52か所のID参照、16ページのデータ検証を通過し、不正タグ・必須項目欠落・ID重複の検出も確認しました。

実行環境の制約により、HTTPプレビューサーバーは起動できず、公開用Gitホストにも接続できませんでした。サイトは登録済みですが未公開です。ブラウザーによる画面の目視確認は未実施です。`AI_Security_Observatory_v0.1.html` は全データを内包し、ダウンロードして通常のブラウザーで開くための独立した確認用コピーです。公開用のソースとは分離しています。
